# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student marks and generates performance reports.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV

## Features
- Stores marks for 20 students
- Calculates total marks and average
- Assigns grades and Pass/Fail results
- Identifies the class topper
- Calculates class average
- Performs subject-wise performance analysis
- Exports student results to a CSV file
- Displays failed students

## How to Run
1. Install Python.
2. Install the required libraries:
   `python -m pip install numpy pandas`
3. Run the program:
   `python main.py`

## Output
The program displays student results, class statistics, subject-wise analysis, and saves the results in `student_results.csv`.
